# التحقق من Invoice Studio

التحقق: 4 أكتوبر 2026، على جهاز Windows الحالي.

## النتائج

- 14 اختبار backend ناجحة: عقد OpenAI وبنية التصنيفات، المراجعة والحفظ، فصل اقتراح AI عن القرار النهائي، التنبيهات، خارج النطاق، الثقة المنخفضة، القيم الناقصة، فشل التحليل، PDF متعدد الصفحات، إعادة المحاولة، الحدود والملفات التالفة، واستعادة المعالجة المنقطعة.
- 4 اختبارات React ناجحة: تصحيح الحقول والتصنيف دون تغيير الأصل، إقرار التنبيهات والاعتماد بلا تصنيف، عرض جدول OCR مع تنقية المحتوى، واتجاه قراءة الفواتير العربية ذات الشعار الإنجليزي والفواتير الإنجليزية.
- اختبارا Playwright ناجحان على Microsoft Edge: الرفع والقراءة والتحليل والمراجعة والحفظ وإعادة الفتح، ثم PDF متعدد الصفحات وعرض الجوال بعرض 390px دون امتداد أفقي للصفحة.
- بناء TypeScript/Vite ناجح. فُصل تحميل مساحة الوثيقة عن الصفحة الرئيسية لتخفيف التحميل الأولي.
- `npm audit` لم يجد ثغرات معروفة بعد تحديث الحزم.

بدائل OCR وOpenAI المستخدمة في اختبارات الفلو موجودة في ملفات الاختبار فقط، وخادم E2E يستعمل قاعدة وملفات منفصلة عن التطبيق الحقيقي. سيناريوهات التصنيف ذات النتائج المحددة تختبر العقد والفلو، ولا تثبت جودة تصنيف النموذج الحقيقي.

## التجربة الحقيقية من الواجهة

رُفعت الصورة السابقة من زر الرفع في واجهة التطبيق، وقرأها LightOnOCR-2-1B المحلي باستخدام Q8_0 للنص وF16 للرؤية وCPU فقط. معرّف الوثيقة:

`bd8f6034-e358-4859-9f49-938ba0b0578d`

- صفحة واحدة؛ القراءة اكتملت بسبب `stop` وليست نتيجة مقطوعة.
- زمن القراءة بعد جاهزية النموذج: 217.23 ثانية، نحو 3 دقائق و37 ثانية.
- 2159 input tokens و787 output tokens.
- 1609 أحرف، مطابقة تمامًا للناتج الخام المحفوظ في التجربة السابقة.
- ظهرت الصورة الأصلية والنص المنسق وجدول البنود والنص الخام في شاشة الوثيقة.
- توقف التحليل الأول برسالة `openai_not_configured` مع بقاء قراءة OCR محفوظة. بعد إعداد المفتاح محليًا أُعيدت مرحلة التحليل فقط ونجحت عبر Responses API والمخرجات المنظمة.

نجح تحليل OpenAI الحقيقي باستخدام `gpt-6-luna` في 5.28 ثانية. استخرج `INV-1042`، المورد XYZ للمقاولات والصيانة، تاريخ `2024-05-20`، العملة SAR، المجموع الفرعي 14,250 والضريبة 2,080 والإجمالي 16,330 وثلاثة بنود. اقترح قيمة تصنيف فارغة لأن صيانة التكييف خارج الفئات التقنية الأربع. بقيت الوثيقة `needs_review` بسبب اختلاف مجموع البنود 17,250 عن المجموع الفرعي 14,250. لم تُصحّح الأرقام المكتوبة تلقائيًا ولم تُعتمد المراجعة نيابة عن المستخدم. زمن OCR الخام السابق بقي 217.23 ثانية ولم تتكرر قراءته. هذه تجربة واحدة ولا تقيس الدقة العامة للتصنيف. لم تُستخدم البيانات اليدوية السابقة كأنها مخرجات AI داخل التطبيق.

المعاينة الفعلية وقياسات التجربة المحلية محفوظة في `.local/verification/`، ومهملة من Git. النتائج والوثيقة الأصلية محفوظة في `.local/invoice-app/`.

## إضافة Regex — 5 أكتوبر 2026

- 31 اختبار backend و5 اختبارات React و3 اختبارات Playwright ناجحة، مع بناء TypeScript/Vite.
- أصبح Regex وقارئ HTML/Markdown مسار الاستخراج الافتراضي المحلي؛ لا يُستدعى OpenAI فيه ولو كان المفتاح موجودًا.
- نتيجة المقارنة على قراءة الفاتورة السابقة محفوظة منفصلة: سبعة حقول وثلاثة بنود، وزمن الاستخراج الأول عبر API نحو 66.2ms (دون OCR). قياس مئة عملية داخل العملية أعطى وسيطًا نحو 1.9ms؛ لا يعبر أي منهما عن زمن OCR أو أداء فواتير مختلفة.
- قورنت نتيجة النموذج وصفحات OCR والبيانات النهائية ووقت الاعتماد قبل المقارنة وبعدها، وبقيت مطابقة. لم تُعتمد نتيجة Regex نيابة عن المستخدم.
- اختُبر التبديل بين النتيجتين واعتماد مراجعة Regex مع بقاء النتيجة الأصلية والحفظ بعد إعادة الفتح.
- التفاصيل والحدود في docs/regex-extraction.md.
# تحسين Regex v2 — 5 أكتوبر 2026

48 اختبار backend و7 اختبارات React و3 اختبارات E2E نجحت. تشمل التحسينات العنوان قبل القيمة وبعدها، الفقرات التي تحتوي `<br>`، محاذاة `rowspan/colspan`، استخراج الإجماليات في الاتجاهين، المطابقة التقريبية المحدودة وتنبيهاتها، وعدم التقاط أرقام تالفة جزئيًا. اختبارات المقارنة تضمن حفظ النتائج والمراجعات السابقة، وربط المراجعة بمعرّف النتيجة، ورفض اعتماد نتيجة تغيرت في الخلفية.

على القراءات الأربع المحفوظة، استُخرجت سبعة حقول لكل وثيقة وبنودها (2/2/2/3). فاتورة الرواد التي فشلت سابقًا استُخرج منها SAL-2024-0876 والمورد الكامل والتاريخ و7900/1185/9085/SAR والبندان. دليل عنوان الإجمالي يبين المطابقة التقريبية، وتبقى المراجعة مطلوبة. تمت مقارنة الأصل وOCR ونتيجة الاستخراج الأساسية وتصحيحات المستخدم قبل/بعد إعادة الاستخراج، وظلت كما هي. لم تُشغّل OCR أو طلبات تحليل خارجية لهذا الفحص.

قياس استخراج نص الرواد 100 مرة داخل العملية: وسيط 3.46ms وP95 5.25ms، دون OCR والشبكة والتخزين والعرض. سجّل الاستخراج في أول طلب للمقارنة 21.26ms. التقرير المحلي `.local/verification/regex-v2-report.json`. هذه عينة تطوير صغيرة لا تثبت دقة إنتاج عامة.

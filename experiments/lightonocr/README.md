# Local LightOnOCR experiment

This directory reproduces the attached handwritten-invoice OCR experiment. It is an experiment, not a production extraction service.

The setup downloads the CPU Windows llama.cpp release b11387 and pinned LightOnOCR-2-1B GGUF weights (text Q8_0, vision F16), checks SHA256, and stores large files under the ignored `.local/lightonocr/` directory. It requires Python and `requests`. The setup currently defaults to the original attached image's local path; the OCR runner accepts any local image path.

From the repository root:

```powershell
python experiments/lightonocr/setup_runtime.py
python experiments/lightonocr/run_ocr.py
```

To test another PNG or JPEG with the cached model:

```powershell
python experiments/lightonocr/run_ocr.py --image 'D:\invoices\sample.png' --name sample-01
```

The runner starts a temporary llama.cpp server on 127.0.0.1:18987, sends an image-only request, preserves the raw response and timings, and stops its server afterward. No image is sent to an external service. PDF rendering is outside this experiment.

Results are under `results/<name>/`. Use a new name per run: an existing result name will be overwritten. The initial comparison is in `results/original-q8/report.md`; `reviewed_fields.json` is human-reviewed organization of the OCR text, not JSON generated by an extraction LLM.

The reference was manually prepared before inference. Matching the written invoice values is evaluated separately from checking its arithmetic; the image itself contains contradictory amounts.
